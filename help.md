### Set Up Your Wiro AI Key

1. Sign up at [wiro.ai](https://wiro.ai) and create a project at [wiro.ai/panel/project/new](https://wiro.ai/panel/project/new).
2. Open the project at [wiro.ai/panel/project](https://wiro.ai/panel/project) and copy its API key into **API Key**.
3. If you chose signature-based authentication for the project, copy its API secret into **API Secret** too. Leave it empty for an API Key Only project.

Runs and chat messages are charged to the project's wallet at each model's price.
