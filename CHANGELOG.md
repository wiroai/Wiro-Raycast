# Wiro AI Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Generate Image: pick a text-to-image model from the Wiro AI catalog, write a prompt and see the price for your settings before you run it
- Edit Image: edit an image from Finder or the clipboard with a prompt, upscale it, remove its background or restore an old photo
- Generate Video: make a video from a prompt or from an image, follow the task and cancel it if you need to
- Generate Speech: read the selected text aloud with the model and voice you pick
- Generate Music: make music or a song from a prompt
- Transcribe Audio: turn an audio file into text
- Ask AI: chat with LLMs through the Wiro AI LLM gateway, with a model picker and follow-up questions
- Search Models: search the catalog by name or category, see details and prices, and open a model in the right form
- Run Any Model: run any model in the catalog with a form built from its inputs
- Run Workflow: run your workflows with their inputs and get every result
- Message Agent: message your deployed agents and read their replies
- Task History: browse your recent tasks with their results, cost and run time
- Wallet Balance: see your balance in the menu bar
- Results can be copied, saved to Downloads, shown in Finder or previewed with Quick Look
